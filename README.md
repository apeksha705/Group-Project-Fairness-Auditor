# AI Fairness Auditor

## Overview
AI Fairness Auditor is a web-based application designed to analyze team collaboration data and identify fairness, contribution balance, and potential bias in group projects. It helps mentors and students visualize contribution metrics and receive AI-generated recommendations for improving collaboration.

## Problem Statement
In group projects, it is often difficult to measure each member's actual contribution fairly. Traditional evaluation methods rely on manual observation, which can introduce bias.

AI Fairness Auditor aims to:
- Measure contribution fairness.
- Detect contribution imbalance.
- Visualize team performance.
- Provide AI-based recommendations for improvement.
